# LoopFlow Toolkit — 決策紀錄（第一輪）

> 本檔只保存待裁決與裁決結果。現況證據見 [`程式盤點.md`](./程式盤點.md)，工程方案見 [`架構建議.md`](./架構建議.md)。

## 建議強度

| 強度 | 意義 |
|---|---|
| **強烈建議** | 關係到資料安全、可復原、避免靜默錯誤或長期可維護性；若不採用需有同等安全替代方案 |
| **一般建議** | 可以改，但要接受額外操作或維護成本 |
| **輕鬆建議** | 不影響核心資料鏈，可依使用習慣與介面偏好調整 |
