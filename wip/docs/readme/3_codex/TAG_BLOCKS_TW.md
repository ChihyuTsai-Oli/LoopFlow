# LoopFlow 2.0 Tag Block 說明

> 本文件說明 `Tag_Blocks.3dm` 圖塊庫裡各種 Tag／圖框圖塊，畫面上每個欄位代表什麼、誰會寫入、使用者可以手動改哪裡。指令怎麼操作見 [指令逐項說明](./COMMANDS_TW.md)；整體流程見 [使用說明總覽](./USER_GUIDE_TW.md)。
>
> 2.0 只維護**一份** `wip/docs/Tag_Blocks_3dm/Tag_Blocks.3dm`，檔內同時有繁中與英文說明，不另做中／英兩個 3dm。圖塊上的固定標籤（`Grab`、`Laser`、`W.`、`H.`）是設計時就寫死的文字，不是資料欄位；公式預設提示維持英文。日後安裝包會把這份圖塊庫放到「文件\LoopFlow」，方便複製到各專案（尚未打包）。
>
> 本文件以契約中的標準名稱為準：`TAG_HEIGHT_GRAB`、`TAG_HEIGHT_LASER`、`TAG_FINISH_GRAB`、`TAG_FINISH_LASER`、`TAG_ITEM`、`TAG_DW`、`TAG_SECTION_DETAIL`、`TAG_ELEV_1`、`TAG_ELEV_2`、`TAG_ELEV_3`、`TAG_ELEV_4`、`TAG_ELEV_0`、`Sample_Frame`。Rhino 既有定義若顯示為 `Tag_Height_Grab` 等大小寫變體，仍以不分大小寫方式比對。

## 先選對 Tag

| 想標示的內容 | 用哪個 Block | 用哪支指令 |
|---|---|---|
| 物件高程與材質，可以直接點選來源 | `TAG_HEIGHT_GRAB` | [10 直接抓取](./COMMANDS_TW.md#10-直接抓取) |
| 物件高程與材質，只有剖面上的位置 | `TAG_HEIGHT_LASER` | [09 雷射投影](./COMMANDS_TW.md#09-雷射投影) |
| 材質／Type，不需要高程，可以直接點選 | `TAG_FINISH_GRAB` | [10 直接抓取](./COMMANDS_TW.md#10-直接抓取) |
| 材質／Type，不需要高程，只有剖面位置 | `TAG_FINISH_LASER` | [09 雷射投影](./COMMANDS_TW.md#09-雷射投影) |
| 家具或其他共用圖塊 | `TAG_ITEM` | [10 直接抓取](./COMMANDS_TW.md#10-直接抓取) |
| 門窗編號、寬、高 | `TAG_DW` | 純手動，不綁定任何指令 |
| 剖面詳圖索引 | `TAG_SECTION_DETAIL` | [11 對應視圖](./COMMANDS_TW.md#11-對應視圖) |

| 圖框（圖號／圖名／比例） | 專案圖框（例如 `Sample_Frame`） | [07 圖號命名](./COMMANDS_TW.md#07-圖號命名) |

## 先看懂四個共通概念

### 1　欄位是「自動」還是「手動」

每個 Tag 上的欄位分兩種：

- **自動欄**：由 [12/13 注入資料](./COMMANDS_TW.md#1213-注入資料) 或 [07 圖號命名](./COMMANDS_TW.md#07-圖號命名) 寫入，使用者不要手動改——下次注入／編號會被覆寫。
- **手動欄**：使用者自己填寫，指令不會覆寫它（複製 Layout 時例外，見下方「複製後會怎樣」）。

本文件每張欄位表都會標明「自動」或「手動」。

### 2　畫面上看到 `-`／`!`／`?` 是什麼意思

這是 [14 健康檢查](./COMMANDS_TW.md#14-健康檢查tag-o) 與 12/13 注入資料共用的提示慣例，只出現在**自動欄**：

| 符號 | 顏色 | 意思 |
|---|---|---|
| `-` | 不塗色 | 這顆 Tag 還沒綁定來源 |
| `!` | 整顆塗橘 | 過期：來源還在，畫面資料不是最新的——重新注入就會恢復 |
| `?` | 整顆塗紅 | 斷連：來源不見了——要先重新綁定，再重新注入才會恢復 |

### 3　鎖定怎麼用

大部分 Tag 左上角有一個鎖定欄，畫面輸入 `x` 或 `X` 就代表鎖定（欄名 `lf_00_lock_state`，數字 `00` 只是讓這一欄在 Rhino 的屬性列表排在最上面，方便找）。

- 鎖定後：**綁定會被凍結**，[09 雷射投影](./COMMANDS_TW.md#09-雷射投影)／[10 直接抓取](./COMMANDS_TW.md#10-直接抓取)／[11 對應視圖](./COMMANDS_TW.md#11-對應視圖)、以及 12/13 注入資料都不會再改動這顆 Tag。
- [14 健康檢查](./COMMANDS_TW.md#14-健康檢查tag-o) 仍然會把鎖定的 Tag 列出來並標註「鎖定」，但不會改它的文字或顏色。
- 空白，或畫面上的預設提示文字（`x to lock`），都不算鎖定。
- `TAG_DW`（門窗）與圖框**沒有**鎖定欄。

### 4　不要手動改的系統欄位

除了本文件標明是「手動」的欄位以外，Tag 身上還有一些不會顯示在圖面上、但 LoopFlow 用來辨認身分的系統欄位，例如 Tag 編號、綁定模式、來源物件 ID、目標 View／Sheet、同步版次、健康狀態。**這些不要直接編輯**——綁錯了就重新用 Grab／Laser／Index 綁一次，不要手動改這些隱藏欄位，否則系統會認不出正確的來源或目標。

## Height Tag — 高程標註

**圖塊**：`TAG_HEIGHT_GRAB`、`TAG_HEIGHT_LASER`　**綁定方式**：[10 直接抓取](./COMMANDS_TW.md#10-直接抓取) 或 [09 雷射投影](./COMMANDS_TW.md#09-雷射投影)

標註物件的高程（例如窗台、天花板高度）。

| 畫面欄位 | 誰寫入 | 說明 |
|---|---|---|
| 鎖定 | 手動 | `x`／`X` |
| 高程基準 | 自動 | 來源物件的量測基準：`BH`（底面）／`TH`（頂面）／`CH`（天花板底面）／`BC`（圖塊插入基準點，只用在圖塊物件） |
| 高程數值 | 自動 | 顯示字串，可能含 `+`、`±0` 等符號，不是給計算用的純數值 |
| 材質類別 | 自動 | 來源物件的 Type 類別碼，例如 `PT` |
| 材質序號 | 自動 | 來源物件的 Type 序號，例如 `00` |
| 材質名稱 | 自動 | 對應字典裡的 Type 顯示名稱 |
| 備註 | 手動 | 預設提示「Enter」，使用者自行輸入 |

## Finish Tag — 材質標註

**圖塊**：`TAG_FINISH_GRAB`、`TAG_FINISH_LASER`　**綁定方式**：[10 直接抓取](./COMMANDS_TW.md#10-直接抓取) 或 [09 雷射投影](./COMMANDS_TW.md#09-雷射投影)

標註表面材質，不含高程欄位。

| 畫面欄位 | 誰寫入 | 說明 |
|---|---|---|
| 鎖定 | 手動 | `x`／`X` |
| 材質類別 | 自動 | 來源物件的 Type 類別碼，例如 `MT` |
| 材質序號 | 自動 | 來源物件的 Type 序號 |
| 材質名稱 | 自動 | 對應字典裡的 Type 顯示名稱 |
| 備註 | 手動 | 預設提示「Enter」 |

## Item Tag — 家具／設備標註

**圖塊**：`TAG_ITEM`　**綁定方式**：[10 直接抓取](./COMMANDS_TW.md#10-直接抓取)（選家具圖塊）

| 畫面欄位 | 誰寫入 | 說明 |
|---|---|---|
| 鎖定 | 手動 | `x`／`X` |
| 家具類別 | 自動 | 來自圖塊名稱前段，例如 `FF-01__Chair-1` 的 `FF` |
| 編號 | 自動 | 圖塊名稱中段，例如 `01` |
| 名稱 | 自動 | 圖塊名稱後段，例如 `Chair-1` |
| 備註 | 手動 | 預設提示「Enter」 |

同款家具可以共用同一個圖塊名稱（例如同一批椅子都叫 `FF-01__Chair-1`）。Grab 綁定時會連同**這一個實例**一起記下來，所以之後改圖塊名稱，畫面會自動更新；如果這個實例被刪除，會顯示斷連（`?`）。名稱格式不對會被擋下並警告，系統不會自己猜要怎麼拆。

## DW Tag — 門窗標註

**圖塊**：`TAG_DW`　**綁定方式**：完全手動，不透過任何 Tagger 指令

| 畫面欄位 | 誰寫入 | 說明 |
|---|---|---|
| 編號 | 手動 | 門窗編號 |
| 寬 | 手動 | `W.` 標籤後面的數字，標籤本身不要改 |
| 高 | 手動 | `H.` 標籤後面的數字，標籤本身不要改 |

`TAG_DW` **沒有鎖定欄**，因為全部內容都是人工填寫——12/13 注入資料完全不會碰它，[14 健康檢查](./COMMANDS_TW.md#14-健康檢查tag-o) 也不會因為它沒有來源就當成「未綁定」來標記，[複製 Layout](./COMMANDS_TW.md#a4-複製-layout) 時內容也會完整保留，不會被清空。

## Index Tag — 詳圖／立面索引

**圖塊**：`TAG_SECTION_DETAIL`、`TAG_ELEV_1`～`TAG_ELEV_4`　**綁定方式**：[11 對應視圖](./COMMANDS_TW.md#11-對應視圖)

指到某一個已經登記的 View（剖面／立面），讓使用者知道「這裡的詳圖／立面在哪一頁」。四個立面圖塊外觀不同（對應不同方向或版式），但欄位規則相同。

| 畫面欄位 | 誰寫入 | 說明 |
|---|---|---|
| 鎖定 | 手動 | `x`／`X` |
| 圖號 | 自動 | 目標頁的圖號（由 12/13 從目標 Sheet metadata 算出） |
| Ref | 自動 | 目標頁的參照碼 |
| Detail 編號 | 手動 | 例如 `A`、`B`、`1`，供同一頁有多個 Detail 時區分，注入不會寫這欄 |

重新編排圖號（例如插頁）之後，通常只需要重新跑一次 12/13 注入資料，不必重新執行 11 對應視圖——綁定的是 View，不是圖號本身。

## Elev 0 — 六方向立面索引牌

**圖塊**：`TAG_ELEV_0`　**綁定方式**：不透過 Tagger 指令綁定模型，但**目前頁圖號**由 [07 圖號命名](./COMMANDS_TW.md#07-圖號命名) 寫入

放在平面圖上的索引牌，標示這個位置往四個方向、上、下各對應哪張立面圖。它**不是**一般的 Index Tag，不接受 11 對應視圖綁定。

| 畫面欄位 | 誰寫入 | 說明 |
|---|---|---|
| 鎖定 | 手動 | `x`／`X`；鎖定時 07 也不會覆寫「目前頁圖號」 |
| 目前頁圖號 | 自動 | 由 07 圖號命名寫入，代表這個索引牌**所在**的那一頁圖號 |
| 編號 | 手動 | 索引牌流水編號 |
| 立面 | 手動 | 對應立面方向 |
| 上／左／下／右 | 手動 | 對應四個方向各自的立面圖號 |

[14 健康檢查](./COMMANDS_TW.md#14-健康檢查tag-o) 不檢查這個圖塊。[複製 Layout](./COMMANDS_TW.md#a4-複製-layout) 後，方向欄會被清空，等使用者在新頁重新填寫。

## 圖框（Title Frame）

**圖塊**：專案實際使用的圖框，例如 `Sample_Frame`　**綁定方式**：[07 圖號命名](./COMMANDS_TW.md#07-圖號命名) 寫入圖號與圖名

圖框沒有鎖定欄，只能透過 07 的核對清單控制要不要寫入。

| 畫面欄位 | 誰寫入 | 說明 |
|---|---|---|
| 圖號 | 自動 | 07 依系列與尾數自動算出 |
| 圖名 | 自動 | 07 依 Layout 頁名第三欄寫入 |
| 比例 | 手動 | 每張圖自己填，07 不會動這一欄；缺這個欄位時畫面會顯示 `####`（不是指令壞掉，是 Rhino 找不到這個欄位） |

**只有登錄過的圖框才會被處理。** 如果 07 遇到不認識的圖塊，會列出名單讓使用者勾選「這是不是真正的圖框」，預設全部不勾。專案自訂的圖框（不是內建的 `Sample_Frame`）必須先在這個清單裡勾選過一次，之後才會持續被 07 處理。一頁應該只有恰好一個已登錄圖框；沒有或有兩個以上，該頁會被跳過。

## 複製 Layout 後 Tag 會怎樣

執行 [A4 複製 Layout](./COMMANDS_TW.md#a4-複製-layout) 後：

- 除了 `TAG_DW` 之外，所有 Tag 的綁定都會被清掉，整顆改成斷連樣式（`?`，塗紅），提醒重新綁定。
- 手動欄位（備註、Detail 編號、立面方向等）會被寫成一個空白字元，只是為了保留欄位本身、避免畫面顯示 `####`，不算「有內容」。
- **鎖定狀態不會被改變**，畫面上的 `x` 也會保留。
- `TAG_DW` 的編號、寬、高完整保留，不受影響。
- 內建圖框與曾由 07 登錄的專案自訂圖框，都會取得新的 Sheet 身分；圖號、圖名會清空等重跑 07，但比例保留。
- 圖目錄定位點會取得新的目錄身分；原本綁來源 Sheet 的定位點在複本中改綁新 Sheet，避免原頁與複本互相覆蓋。

複本要進圖目錄前，請先重新執行 07 圖號命名，讓新頁的圖號、圖名與 Sheet metadata 完整就緒。

## 遇到不認得的 Block

LoopFlow 只處理 `Tag_Blocks.3dm` 契約裡已經登錄的 Block（本文件列出的這幾種，加上專案登錄過的圖框）。遇到不認得的圖塊時，需要解讀 Tag 契約的指令會維持零寫入，並依該指令的流程回報或略過：

- **不會寫入任何資料**；若該流程有報告，會列出名稱供人工判斷。
- 不會用名稱相似度去猜它是不是某種已知 Tag。
- 不會自動把一般圖塊當成圖框登錄——圖框一定要在 [07 圖號命名](./COMMANDS_TW.md#07-圖號命名) 的清單裡手動勾選過。
