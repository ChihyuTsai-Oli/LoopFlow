# LoopFlow 2.0 使用說明 / Documentation

LoopFlow 2.0 是供 Rhino 8 使用的半自動化工作鏈，連接 Type Dictionary、3D 模型資料、圖面、Sheet 與 Tag。使用者可以分階段執行、檢查、重跑或取消，不必把整條流程一次跑完。

LoopFlow 2.0 is a staged workflow for Rhino 8 that connects the Type Dictionary, 3D model data, drawings, sheets, and tags. Each stage can be run, checked, repeated, or cancelled independently.

> **重要 / Important**
>
> LoopFlow 1.x 與 2.0 的資料、工具列和指令不可在同一工作檔混用。
>
> Do not mix LoopFlow 1.x and 2.0 data, toolbars, or commands in the same working file.
