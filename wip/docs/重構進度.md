| 2 | 從字典同步 Type Layers | 寫圖層／`DNA_REF_` 點；不改物件 instance |
| 3 | 登記高程框（封閉曲線） | 寫 `_15_樓層高程*`、樓層 ID；不寫物件名稱 |
| 4 | 登記空間框（封閉曲線，須在高程框內） | 寫空間名稱／空間 ID／樓層 ID；不寫物件名稱 |
| 5 | 寫入模型 Metadata | 寫物件 `_01`～`_14`（ID／Type／空間／高程／備註／版次）；不寫寬深高 |
| 6 | 檢核模型 Metadata（不寫入） | 不寫；不符的物件一次選取 |

專案設定在 `.3dm` 旁的 `_LoopFlow_Config/LoopFlow_Project.json`，不寫進 `.3dm`：專案名稱存 `layer_prefix` 與 `project_id`（Nexus 選單 2 一併寫入），`schema_id`／`schema_version` 第一次跑指令可順便寫入，字典檔名存 `dictionary_filename`。Dictionary 放在 `.3dm` 同一層。Registry 在 `_LoopFlow_Config/<專案名稱>/`。
