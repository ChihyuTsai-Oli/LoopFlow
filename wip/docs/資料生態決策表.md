# LoopFlow 2.0 — 資料生態決策表

這是 `資料生態藍圖.md` 的使用者編輯區。藍圖保存現況、工作鏈與架構說明；所有尚未定案、需要使用者確認或補充實務語意的事項集中在本文件。原本散落在 Nexus／Dictionary 菜單的 `ND-*` 細項也已併入本檔，避免同一問題有兩套答案。

## 使用方式

- 可以直接修改表格中的「你的決定／說明」，不需要使用固定回覆格式。
- 「AI 建議整合／衝突」整理兩位 AI 的共同結論或做法差異；任一 AI 明確標為「強烈建議」且做法不衝突的安全措施，直接納入「你的決定／說明」。
- 若強烈建議只涵蓋一部分，只採用該部分，其餘實務語意維持待決定；若兩位 AI 的具體做法衝突，只採用無衝突的共同安全底線，衝突部分維持待決定。
- 可以把 `待決定` 改成「採用」、「不採用」，或直接寫自己的規則。
- 可以改寫建議內容；若選項不符合實務，直接刪掉重寫也可以。
- 請保留 `ECO-*`／`ED-*`／`ND-*` 編號，方便後續追蹤與回寫。
- ND 細項若標示「由某 ECO／ED 統一裁決」，只填上方對應列，避免同一問題出現兩個答案。
- AI 讀取你的修改後，先整理歧義與影響，再同步回寫藍圖、命名與資料契約、Nexus／Dictionary 盤點及進度紀錄。
- 在回寫完成前，本文件是尚待確認事項的唯一來源；不要同時在藍圖與本文件維護兩份答案。

### AI 建議強度

本輪自動裁決日期：2026-08-14。依使用者指示，任一 AI 的強烈建議直接採用；若強烈建議只涵蓋部分安全措施或兩位 AI 的具體做法衝突，僅採用無衝突部分，其餘維持待決定。

| 強度       | 意義                                                      |
| -------- | ------------------------------------------------------- |
| **強烈建議** | 最好照做；這通常關係到資料不斷鏈、可復原、避免靜默錯誤或能否長期擴充。若不採用，需要先設計同等安全的替代方案。 |
| **一般建議** | 可以改，但會增加相應的規則、操作或維護成本；決定時需明確接受代價。                       |
| **輕鬆建議** | 原則上不影響核心資料鏈，可依實際習慣、時程或介面偏好調整。                           |
