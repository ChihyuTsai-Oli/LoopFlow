# LoopFlow 2.0 教學步驟

- 日期：2026-08-25
- 對象：新使用者（不假設看過 1.0）
- 產品：Package Manager 的 LoopFlow **2.0.5**
- 本檔用途：錄影分鏡。指令細節見公開 `docs/COMMANDS_TW.md`；工作邏輯見 `工作流程.md`。

口白用畫面上的按鈕名稱。若唸命令列，用無底線正式名（例如 `LFNexus`）。1.x 與 2.0 不可混用、不可同檔同按鈕。

核心一句話：**先自由建模，再由字典灌入資料，最後銜接給 2D。** 2D 不會在沒人按的情況下自己更新；每步由使用者執行，系統先報告影響再寫入。

---

## 拍攝順序（10 步）

```text
1  安裝、存檔、拷字典與 Tag、語系、Document
2  字典簡介，Nexus[1][2]，匯入模型並換圖層
3  Nexus[3][4][5]，Data Viewer，Nexus[6]，Publish
4  改圖層（新增／刪除／更名），Export → 開匯出檔 → 開正式字典，手動合併
5  Nexus[2][5][6]，Publish，同資料夾拆 3D／2D，建 rws
6  ClippingSections，Anchor Frame，Extract CP
    （此處或示範檔內：Layout、Detail、圖框、Tag 就位）
7  Duplicate Layout（尚未綁定的頁），Tagger Layout ID，Catalog
8  Tagger Laser／Grab／Index，Infuser Part／All，TAG-O
9  圖紙變更：增刪 Layout／Detail、改名
    → 斷連先重綁 Index；其餘先 Layout ID → Infuser → Catalog → TAG-O
10 改 3D：Nexus[5][6]，Publish，更新 ClippingSections（圖 A）
    → 幾何變了就重 Laser／Grab，再 Infuser、TAG-O
```

修改示範分成三段，每段自己收尾，不要跟主鏈纏在一起：

| 步 | 改什麼 | 收到哪 |
|---|---|---|
| 4～5 | 字典／圖層 | Publish |
| 9 | 圖紙 | Layout ID → Infuser → Catalog → TAG-O |
| 10 | 3D 幾何／資料 | Publish → 更新剖面 → 必要時重綁 → Infuser → TAG-O |

---

## 與 1.0 四集對照

1.0 公開片是四集。2.0 不要原樣套用：第 03 集太滿，且 2.0 多了專案資料夾、高程框、發布、擷取線稿、圖目錄與 TAG-O。

| 1.0 | 2.0 落在哪幾步 | 不要再照 1.0 講的 |
|---|---|---|
| 01 Nexus（Dict to Layer、SpaceBoundary、TagTrigger、TagChecker、Layer to Dict） | 2～4 | Layer to Dict 已離開 Nexus，改為獨立匯出；空間改成高程框＋空間框兩步；TagTrigger／TagChecker 是選單 5／6 |
| 02 Section 與 Anchor Frame | 6 | 發布要在剖面之前（第 3、5 步）；可加 Extract CP |
| 03 Tag Blocks、Layout ID、Laser／Grab／Index、Infuser | 7～8 | 不要提 `NamingRules_Config.json`；圖號用頁名三欄。顏色改為 `-`／`!`／`?`，不要再說紫／橙／紅那套 1.0 含義 |
| 04 改模型後同步 | 9～10 | 中間一定要再 Publish；斷連要重綁，不是只 Infuser |

## 第 1 步　下載安裝與專案設定

**結局**：專案資料夾裡有已存檔的 `.3dm`、正式字典、`Tag_Blocks.3dm`；介面語言已選定。

要示範：

1. Rhino 8 Package Manager 搜 **LoopFlow**，裝 **2.0.5**，完全關掉 Rhino 再開。不要用 1.x 工具列同名按鈕。
2. 開新檔，**先存檔**。已存檔的 `.3dm` 所在資料夾就是專案工作資料夾。
3. 第一次執行任一產品指令會問 English／正體中文（記在這台電腦，不寫進專案）。之後用 **Document 右鍵**切換（`LFLanguage`）。Document **左鍵**只開說明網頁。
4. 官方字典與 `Tag_Blocks.3dm` 會出現在「文件\LoopFlow」（已有不覆蓋；這次有拷才開資料夾）。那是拷貝來源，**不是**專案資料夾。把它們複製到 `.3dm` 同一層。
5. 口白講清楚：Dictionary 與 `.3dm` 同層；`_LoopFlow_Config/` 之後會出現在同層，用來放專案名稱、字典檔名、Registry。整包資料夾一起搬才算同一個專案；只拷 `.3dm` 不會帶走字典與設定。

勿講：某台電腦的 Dropbox 絕對路徑、環境變數 `LOOPFLOW_WORKFILES_ROOT`（2.0 已停用）。

---

## 第 2 步　字典與 Type Layers

**結局**：圖層樹已依字典建好；示範模型的物件已放到對應 Type layer。尚未寫入物件資料。

要示範：

1. 極短翻 Excel：字典是 Type 目錄（每種材質／工項的預設），不是每個 3D 物件的現況表。15 欄細節連字典指南即可。
2. `LFNexus` 選單：
   - **[1] 開案檢查**：確認已存檔、路徑、單位。尚未填專案名稱仍可進選單。找不到字典只警告，用 [2] 指定。
   - **[2] 從字典同步 Type Layers**：問專案名稱（圖層前綴；第一次不預填，建議 `M3D`）。第一次選與 `.3dm` 同層的 `.xlsx`；選到別的資料夾會說明並再問。之後只記住檔名。
3. 匯入既有示範模型（或插入），把物件換到對應 Type layer。LoopFlow 不在背景自動寫資料。

安全停點：圖層建好即可存檔。

---

## 第 3 步　高程、空間、寫入、檢核、第一次發布

**結局**：物件有 Metadata，檢核通過，已有一份 Registry 版次。還沒進 2D。

要示範：

1. Nexus **[3] 登記高程框**：選封閉曲線，選 FFL 或 FL，輸入數字高程（例如 `0`、`320`）。這是 2.0 寫高程的基準，1.0 沒有獨立講。
2. Nexus **[4] 登記空間框**：封閉曲線須在高程框內（共邊可）；一次可選多條、同一個空間名稱。重疊會停下來列出衝突，不自動選。跨兩個空間的物件，寫入時會 zoom 再讓人選。
3. Nexus **[5] 寫入模型 Metadata**：尚未做 [3][4] 會停止、不寫入。含隱藏／鎖定物件。
4. `LFDataViewer`：點物件只讀看 `_01`～`_14`（高程框另有 `_15`）。不寫入。
5. Nexus **[6] 檢核模型 Metadata**：只比對不寫入。不符會列出差異並選取那些物件，請回 [5]。
6. `LFPublishExchange`：**必須 [6] 通過後**才發布。整案發布，不能只選一部分。產出在 `_LoopFlow_Config/<專案名稱>/Project_Registry.json`。這是給 2D 讀的唯讀快照；沒發布，後面的 Infuser 沒有「通過檢核的那一版」。

口白強調：寫完 Metadata ≠ 圖紙會自己更新。2D 讀的是發布出來的版次。

## 第 4 步　修改圖層與手動更新字典

**結局**：觀眾知道模型圖層與正式字典不同步時，怎麼核對、怎麼手動合併。此時先不要再寫入 Metadata。

要示範（順序固定）：

1. 在 Rhino 新增／刪除／更名 Type layer（可把部分物件換到新層）。
2. `LFExportTypeLayers`：在字典同層產出 `{原檔名}_Export.xlsx`。
3. `LFOpenDictExport`：**先開匯出檔**。紅＝字典有、模型沒有；藍＝模型新增；橙＝兩邊內容不同。第一列紅字：此檔不能當正式字典、不可覆寫正式檔。藍列合併時必須給**還沒用過的** Type ID。
4. `LFOpenDictionary`：開正式字典，手動把需要的列抄回去。

匯出與開啟都是獨立指令，不是 Nexus 選單步驟。不要把匯出檔設成 Nexus 選中的正式字典。

---

## 第 5 步　同步回來、再發布、拆 3D／2D

**結局**：字典與圖層對齊，新版 Registry 已發布；3D 與 2D 分成兩個檔，用 Worksession 連在一起。

要示範：

1. Nexus **[2]**：把合併後的正式字典同步回圖層。
2. Nexus **[5][6]**，再 `LFPublishExchange`。
3. 另存／新建 **2D 檔**，與 3D 檔放在**同一個資料夾**。Registry 跟目前作用中的 `.3dm` 所在資料夾走；參照檔在別的資料夾不會自動共用 `_LoopFlow_Config`。
4. 用 Rhino Worksession 建 `.rws`，讓 2D 檔 Attach 3D 檔。
5. 之後：Nexus／Publish 在 **3D 檔**做；剖面、Layout、Tag、Infuser、Catalog 在 **2D 檔**做。
6. 可口頭提 `LFSyncWorksession`：監看同資料夾 `.3dm`，閒置後自動 Refresh。只 Refresh，不幫你 Attach。不是主步驟。

---

## 第 6 步　剖面、錨定框、擷取線稿

**結局**：2D 模型空間裡有剖面線稿與錨定框。可選做 Extract。

要示範：

1. Rhino 8 原生 `ClippingSections`／Section（LoopFlow 不做自己的剖切工具）。
2. `LFAnchorFrame`：在 **2D 模型空間**（不要在 Layout）框選該剖面的線／填充，以及**恰好一個** Text Dot（文字要能對到 Clipping Plane 名稱）。外擴距離預設 50。
3. 鐵律：不要刪錨定框；2D 圖平移時框必須一起走。只平移不必重跑；重新剖切、旋轉、額外鏡射才要重跑。天花／RCP 先鏡射再登記。
4. 選用 `LFExtractCP`：圖 A＝Section 連動線稿（不編）；圖 B＝可編輯複本。Laser 兩種都能打，點必須落在已登記框內。第 10 步會對照「更新 Section 只動圖 A」。

**第 6 步結束前必須就位（示範檔已有則口白帶過）：** Layout、Detail（看到剖面）、圖框、要示範的 Tag。Laser／Grab／Index 都在 Layout 裡點進 Detail，沒有這些就無法進行第 8 步。

---

## 第 7 步　複製頁、圖號、圖目錄

**結局**：每頁有圖號／圖名；圖目錄列得出這些頁。Tag 此時**尚未綁定**（或複本尚未綁定）。

要示範：

1. `LFDuplicateLayout`：在尚未綁定 Tag 時複製頁。若等到第 8 步綁定並注入後再複製，複本 Tag 會被清成斷連（紅、`?`），那是變更示範，不要當第一次編圖號。
2. Layout 頁名三欄（不要再提 1.0 的 `NamingRules_Config.json`）：
   - `**圖類別__圖號__圖名`＝系列起點（寫入後保留 `**`，勿刪）
   - 同一系列後面的頁只寫圖名
   - `//圖類別__圖號__圖名`＝手動頁、不佔號
3. `LFTaggerLayoutID`：只勾真正的圖框，不要勾 `tag_*`。先看核對清單再確認。圖號真相是 Sheet metadata，不是頁名字串。比例 `lf_scale` 人工填。插頁或改頁序後要再跑一次。
4. `LFCatalog`：須先有 Layout ID。選圖號定位點、圖名定位點、要列入的 Layout，再生成。

Index 注入的圖號來自這一貫的 Sheet。所以 **Layout ID 必須在第 8 步 Infuser 之前**。

---

## 第 8 步　綁定、注入、健康檢查

**結局**：Tag 畫面上有資料；會用 TAG-O 判斷綠／橘／紅。

要示範：

1. 先選對圖塊：

   | 要標什麼 | 圖塊 | 指令 |
   |---|---|---|
   | 高程＋材質，可點來源 | `TAG_HEIGHT_GRAB` | Grab |
   | 高程＋材質，只有剖面上的點 | `TAG_HEIGHT_LASER` | Laser |
   | 只標材質 | `TAG_FINISH_GRAB`／`LASER` | Grab／Laser |
   | 家具 | `TAG_ITEM` | Grab |
   | 門窗編號寬高 | `TAG_DW` | 純手動，不綁 |
   | 剖面／立面索引 | `TAG_SECTION_DETAIL`、`TAG_ELEV_1`～`4` | Index |
   | 本頁六方向索引牌 | `TAG_ELEV_0` | Layout ID 寫本頁圖號；方向手填 |

2. 鎖定：左上角輸入 `x` 或 `X` 後，綁定與 Infuser 都不再改這顆。
3. 三種綁定擇一或並用，不必三支都跑：
   - `LFTaggerLaser`：點必須落在錨定框內。
   - `LFTaggerGrab`：點進 Detail 再選來源或家具圖塊。
   - `LFTaggerIndex`：從清單選已登記的 Detail。
4. `LFInfuserPart`（本頁）／`LFInfuserAll`（全檔）：規則相同，只差範圍。Height／Finish 先讀 Registry，對不到再讀模型（含 worksession 連結檔）。
5. `LFTagO`：只檢查與上色，不自動修。

畫面符號（與 1.0 不同，務必重講）：

| 符號 | 顏色 | 意思 | 下一步 |
|---|---|---|---|
| `-` | 不塗色 | 還沒綁定 | 先 Laser／Grab／Index |
| （注入後正常） | 綠 | 來源還在、資料是最新 | 不用動 |
| `!` | 整顆橘 | 過期：來源還在，畫面不是最新 | 再 Infuser |
| `?` | 整顆紅 | 斷連：來源或目標 Detail／頁沒了 | 先重綁，再 Infuser。Infuser 不會灌回斷連 Tag |

不要再說 1.0 的紫＝已寫入、橙＝未連結。

---

## 第 9 步　圖紙變更

**結局**：增刪頁、改名、刪 Detail 之後，知道回到哪一個指令，不必重做整套 3D。

建議鏡頭（內部順序固定）：

1. **只改頁名或插頁、沒刪 Detail**：先 `LFTaggerLayoutID`（圖號重排）→ Infuser → Catalog → TAG-O。
2. **刪了 Detail 或目標 Layout**：Index 變斷連。Infuser **不會灌回去**。先重新 `LFTaggerIndex`，再 Infuser。口白不要說「重 Infuser 就好」。
3. Duplicate 若在已綁定之後才做：複本除門窗外會斷連，當新頁重綁；要進圖目錄前先再跑 Layout ID。

---

## 第 10 步　修改 3D 模型

**結局**：改完模型，圖紙跟到同一版次；觀眾能區分「只 Infuser」與「要重綁」。

在 **3D 檔**示範：

1. 改物件（移動、換層、增刪）。空間／高程沒變就不必重跑 Nexus [3][4]。
2. Nexus **[5][6]** → `LFPublishExchange`。

切回 **2D 檔**（Worksession Refresh 或 `LFSyncWorksession`）：

3. 更新 ClippingSections。這只更新 **圖 A**。圖 B（Extract）不會自動跟著改；要嘛繼續用圖 A，要嘛再 Extract（已手動改過的圖 B，取代時不會覆蓋）。
4. 只改屬性、射線仍打到同一件：Infuser 即可。TAG-O 會先橘再變綠。
5. 幾何變了、點位可能打到別的物件：先重新 Laser／Grab，再 Infuser。
6. TAG-O 收尾。

收句：圖會跟著模型走，但不是沒人按就自動改。回到對應節點重跑即可，其他已做好的部分不會被系統擅自修掉。

## 鏡頭勿講

- `NamingRules_Config.json`（1.0 圖號設定，2.0 不用）
- 環境變數找工作檔；字典必須和 `.3dm` 同層
- 某台電腦的 Dropbox 絕對路徑
- 1.x 的紫／橙含義；2.0 用 `-`／`!`／`?`
- 櫃體套件、三個 2D Generator、數量計算（不屬 2.0 主鏈）
- TAG-O 會自動修復（只上色）

## 錄製前

1. 公司電腦裝 2.0.5，關光 Rhino 再開；用 yak 工具列，不要用 1.x 同名按鈕。
2. 開錄第 8 步前，實機跑過 Laser／Grab／Index（確認不再出現找不到套件或 `tag_templates.json`）。
3. 示範 3D／2D 兩個檔放在同一資料夾。
4. 每步結束存檔，當作安全停點；不要一鏡從空檔灌到全案 Infuser。
5. 公開 `docs/` 入口在影片未全部更新前，須註明仍有 1.0 畫面。
6. 若要做英文音軌，流程見 `英文配音計劃.md`（先錄無聲畫面與中文口白）。
