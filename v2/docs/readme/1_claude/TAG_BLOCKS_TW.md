# LoopFlow 2.0 Tag Block 說明

> 本文件說明 `Tag_Blocks.3dm` 圖塊庫裡各種 Tag／圖框圖塊，畫面上每個欄位代表什麼、誰會寫入、使用者可以手動改哪裡。指令怎麼操作見 [指令逐項說明](./COMMANDS_TW.md)；整體流程見 [使用說明總覽](./USER_GUIDE_TW.md)。
>
> 2.0 只維護**一份英文版**的 `Tag_Blocks.3dm`，不另做中文圖塊庫；圖塊上的固定標籤（`Grab`、`Laser`、`W.`、`H.`）是設計時就寫死的文字，不是資料欄位。

## 先看懂三個共通概念

### 1　欄位是「自動」還是「手動」

每個 Tag 上的欄位分兩種：

- **自動欄**：由 [12/13 注入資料](./COMMANDS_TW.md#1213-注入資料) 或 [07 圖號命名](./COMMANDS_TW.md#07-圖號命名) 寫入，使用者不要手動改——下次注入／編號會被覆寫。
- **手動欄**：使用者自己填寫，指令不會覆寫它（複製 Layout 時例外，見下方「複製後會怎樣」）。

本文件每張欄位表都會標明「自動」或「手動」。

### 2　畫面上看到 `-`／`!`／`?` 是什麼意思

這是 [14 健康檢查](./COMMANDS_TW.md#14-健康檢查tag-o) 與 12/13 注入資料共用的提示慣例，只出現在**自動欄**：

| 符號 | 顏色 | 意思 |
|---|---|---|
| `-` | 不塗色 | 這顆 Tag 還沒綁定來源 |
| `!` | 整顆塗橘 | 過期：來源還在，畫面資料不是最新的——重新注入就會恢復 |
| `?` | 整顆塗紅 | 斷連：來源不見了——要先重新綁定，再重新注入才會恢復 |

### 3　鎖定怎麼用

大部分 Tag 左上角有一個鎖定欄，畫面輸入 `x` 或 `X` 就代表鎖定（欄名 `lf_00_lock_state`，數字 `00` 只是讓這一欄在 Rhino 的屬性列表排在最上面，方便找）。

- 鎖定後：**綁定會被凍結**，[09 雷射投影](./COMMANDS_TW.md#09-雷射投影)／[10 直接抓取](./COMMANDS_TW.md#10-直接抓取)／[11 對應視圖](./COMMANDS_TW.md#11-對應視圖)、以及 12/13 注入資料都不會再改動這顆 Tag。
- [14 健康檢查](./COMMANDS_TW.md#14-健康檢查tag-o) 仍然會把鎖定的 Tag 列出來並標註「鎖定」，但不會改它的文字或顏色。
- 空白，或畫面上的預設提示文字（`x to lock`），都不算鎖定。
- `TAG_DW`（門窗）與圖框**沒有**鎖定欄。

## Height Tag — 高程標註

**圖塊**：`Tag_Height_Grab`、`Tag_Height_Laser`　**綁定方式**：[10 直接抓取](./COMMANDS_TW.md#10-直接抓取) 或 [09 雷射投影](./COMMANDS_TW.md#09-雷射投影)

標註物件的高程（例如窗台、天花板高度）。

| 畫面欄位 | 誰寫入 | 說明 |
|---|---|---|
| 鎖定 | 手動 | `x`／`X` |
| 高程基準 | 自動 | 來源物件的量測基準：`BH`（底面）／`TH`（頂面）／`CH`（天花板底面）／`BC`（兩者皆記，例如樓板） |
| 高程數值 | 自動 | 顯示字串，可能含 `+`、`±0` 等符號，不是給計算用的純數值 |
| 材質類別 | 自動 | 來源物件的 Type 類別碼，例如 `PT` |
| 材質序號 | 自動 | 來源物件的 Type 序號，例如 `00` |
| 材質名稱 | 自動 | 對應字典裡的 Type 顯示名稱 |
| 備註 | 手動 | 預設提示「Enter」，使用者自行輸入 |

## Finish Tag — 材質標註

**圖塊**：`Tag_Finish_Grab`、`Tag_Finish_Laser`　**綁定方式**：[10 直接抓取](./COMMANDS_TW.md#10-直接抓取) 或 [09 雷射投影](./COMMANDS_TW.md#09-雷射投影)

標註表面材質，不含高程欄位。

| 畫面欄位 | 誰寫入 | 說明 |
|---|---|---|
| 鎖定 | 手動 | `x`／`X` |
| 材質類別 | 自動 | 來源物件的 Type 類別碼，例如 `MT` |
| 材質序號 | 自動 | 來源物件的 Type 序號 |
| 材質名稱 | 自動 | 對應字典裡的 Type 顯示名稱 |
| 備註 | 手動 | 預設提示「Enter」 |

## Item Tag — 家具／設備標註

**圖塊**：`Tag_Item`　**綁定方式**：[10 直接抓取](./COMMANDS_TW.md#10-直接抓取)（選家具圖塊）

| 畫面欄位 | 誰寫入 | 說明 |
|---|---|---|
| 鎖定 | 手動 | `x`／`X` |
| 家具類別 | 自動 | 來自圖塊名稱前段，例如 `FF-01__Chair-1` 的 `FF` |
| 編號 | 自動 | 圖塊名稱中段，例如 `01` |
| 名稱 | 自動 | 圖塊名稱後段，例如 `Chair-1` |
| 備註 | 手動 | 預設提示「Enter」 |

同款家具可以共用同一個圖塊名稱（例如同一批椅子都叫 `FF-01__Chair-1`）。Grab 綁定時會連同**這一個實例**一起記下來，所以之後改圖塊名稱，畫面會自動更新；如果這個實例被刪除，會顯示斷連（`?`）。名稱格式不對會被擋下並警告。

## DW Tag — 門窗標註

**圖塊**：`TAG_DW`　**綁定方式**：完全手動，不透過任何 Tagger 指令

| 畫面欄位 | 誰寫入 | 說明 |
|---|---|---|
| 編號 | 手動 | 門窗編號 |
| 寬 | 手動 | `W.` 標籤後面的數字，標籤本身不要改 |
| 高 | 手動 | `H.` 標籤後面的數字，標籤本身不要改 |

`TAG_DW` **沒有鎖定欄**，因為全部內容都是人工填寫——12/13 注入資料完全不會碰它，[複製 Layout](./COMMANDS_TW.md#a4-複製-layout) 時內容也會完整保留，不會被清空。

## Index Tag — 詳圖／立面索引

**圖塊**：`TAG_SECTION_DETAIL`、`TAG_ELEV_1`～`TAG_ELEV_4`　**綁定方式**：[11 對應視圖](./COMMANDS_TW.md#11-對應視圖)

指到某一個已經登記的 View（剖面／立面），讓使用者知道「這裡的詳圖／立面在哪一頁」。四個立面圖塊欄位規則相同。

| 畫面欄位 | 誰寫入 | 說明 |
|---|---|---|
| 鎖定 | 手動 | `x`／`X` |
| 圖號 | 自動 | 目標頁的圖號（由 12/13 從目標 Sheet metadata 算出） |
| Ref | 自動 | 目標頁的參照碼 |
| Detail 編號 | 手動 | 例如 `A`、`B`、`1`，供同一頁有多個 Detail 時區分，注入不會寫這欄 |

## Elev 0 — 六方向立面索引牌

**圖塊**：`TAG_ELEV_0`　**綁定方式**：不透過 Tagger 指令綁定模型，但**目前頁圖號**由 [07 圖號命名](./COMMANDS_TW.md#07-圖號命名) 寫入

放在平面圖上的索引牌，標示這個位置往四個方向、上、下各對應哪張立面圖。

| 畫面欄位 | 誰寫入 | 說明 |
|---|---|---|
| 鎖定 | 手動 | `x`／`X`；鎖定時 07 也不會覆寫「目前頁圖號」 |
| 目前頁圖號 | 自動 | 由 07 圖號命名寫入，代表這個索引牌**所在**的那一頁圖號 |
| 編號 | 手動 | 索引牌流水編號 |
| 立面 | 手動 | 對應立面方向 |
| 上／左／下／右 | 手動 | 對應四個方向各自的立面圖號 |

## 圖框（Title Frame）

**圖塊**：專案實際使用的圖框，例如 `Sample_Frame`　**綁定方式**：[07 圖號命名](./COMMANDS_TW.md#07-圖號命名) 寫入圖號與圖名

圖框沒有鎖定欄，只能透過 07 的核對清單控制要不要寫入。

| 畫面欄位 | 誰寫入 | 說明 |
|---|---|---|
| 圖號 | 自動 | 07 依系列與尾數自動算出 |
| 圖名 | 自動 | 07 依 Layout 頁名第三欄寫入 |
| 比例 | 手動 | 每張圖自己填，07 不會動這一欄；缺這個欄位時畫面會顯示 `####`（不是指令壞掉，是 Rhino 找不到這個欄位） |

**只有登錄過的圖框才會被處理。** 如果 07 遇到不認識的圖塊，會列出名單讓使用者勾選「這是不是真正的圖框」，預設全部不勾。專案自訂的圖框（不是內建的 `Sample_Frame`）必須先在這個清單裡勾選過一次，之後才會持續被 07 處理。

## 複製 Layout 後 Tag 會怎樣

執行 [A4 複製 Layout](./COMMANDS_TW.md#a4-複製-layout) 後：

- 除了 `TAG_DW` 之外，所有 Tag 的綁定都會被清掉，整顆改成斷連樣式（`?`，塗紅），提醒重新綁定。
- 手動欄位（備註、Detail 編號、立面方向等）會被寫成一個空白字元，只是為了保留欄位本身、避免畫面顯示 `####`，不算「有內容」。
- **鎖定狀態不會被改變**，畫面上的 `x` 也會保留。
- `TAG_DW` 的編號、寬、高完整保留，不受影響。
- 圖框的圖號、圖名會清空等重跑 07，但比例保留。
