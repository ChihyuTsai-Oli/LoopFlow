# LoopFlow 2.0 使用說明 / Documentation

LoopFlow 2.0 連接 Type Dictionary、Rhino 3D 模型、Section 圖面、Sheet 與 Tag，讓 3D 模型資料能延續到 2D 出圖流程。工作鏈可以分段執行、反覆調整，並在每個節點停下由使用者確認。

LoopFlow 2.0 connects the Type Dictionary, Rhino 3D model, Section drawings, sheets, and tags so model data can continue into the 2D documentation workflow. Every stage can be paused, reviewed, and repeated independently.

## 系統需求 / System Requirements

- **Rhino 8**：LoopFlow 2.0 的 3D／2D 交接依賴 Rhino 8 Section Tools
- **Windows**
- **LoopFlow 2.0**：不可與 LoopFlow 1.x 的資料、工具列或指令混用

- **Rhino 8**: the 3D-to-2D workflow depends on Rhino 8 Section Tools
- **Windows**
- **LoopFlow 2.0**: do not mix its data, toolbars, or commands with LoopFlow 1.x
