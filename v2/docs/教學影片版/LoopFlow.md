## 主片：一個專案走完一張圖

建議錄一條完整案例，章節可獨立跳轉；保留必要的檔案切換、等待與保存結果，重複輸入可剪短。開頭先顯示最終 Layout，再回到空白示範檔。觀眾看得出每次正在操作 3D 檔還是 2D 檔。

## 補片：會改壞流程的兩種情況

1. **字典與圖層差異**：`LFExportTypeLayers` → 看 Export → 人工合併正式字典 → Nexus 2／5／6 → Publish。重點是讀者看懂「匯出檔不是正式字典」，可接圖文 04。
2. **圖紙改版**：插頁／改頁名與刪 Detail 各一例；前者 Layout ID → Infuser → Catalog → TAG-O，後者先重綁 Index。可接圖文 08。

## 錄製要求

- 主片畫面用固定範例，不必示範每一種 Tag 或每個字典欄位；這些細節在章節說明連結圖文。每次執行後稍停，讓結果與檔名可讀。
- 片頭、標題、縮圖與描述寫明 **LoopFlow 2** 與實際安裝版本；YouTube 章節時間碼對應上表。每章描述連到同名圖文頁；圖文首段嵌回主片的對應時間。
- 影片只展示已在示範環境跑通的步驟。拍攝前核對 `TAG_ITEM` 同檔限制、圖 B 修改保護、重疊 Anchor Frame 的選名畫面。不要口述 TAG-O 會修復，或把 1.x 的顏色語意沿用。
- 可沿用舊規劃的「先錄畫面、再寫中文口白」做法；英文音軌是後續選項，不影響繁中圖文先發布。
