# LoopFlow 系列教學（影片版）

> 本資料夾是影片**規劃**。影片為輔、圖文為主；共用示範模型、語言規則與產品順序見 [`../教學圖文版/README.md`](../教學圖文版/README.md)，此處不重複。
>
> 建立日期：2026-10-19

## 定位

每個產品一支**完整操作主片**，用同一個示範案例連續走完；選項細節、錯誤處理與截圖索引交給對應的圖文篇。章節時間碼對應圖文篇號，影片描述連到圖文，圖文首段嵌回影片對應時間。

| 檔案 | 主片 | 初估長度 |
|---|---|---|
| [LoopFlow.md](./LoopFlow.md) | 從模型到一張可更新的圖，另有 2 支補片 | 約 30 分 |
| [R2B.md](./R2B.md) | Rhino 專案進 Blender，再更新一次 | 約 20 分 |
| [R2O.md](./R2O.md) | Rhino 到 Octane 的完整交接 | 約 23 分 |
| [R2M.md](./R2M.md) | Rhino → BIM → Rhino 一輪往返，另有短片 | 約 21 分 |

長度是規劃初估，用來判斷主片是否要拆集；正式剪輯後再更新。單支超過 30 分時，優先拆成「首次設定」與「改版更新」兩集。

## 製作順序

1. 共用示範模型完成，教學副本就位（見圖文版 README）。
2. 該產品圖文篇完成後再錄影，影片不先於圖文。
3. 先錄無聲畫面，再對照畫面錄中文口白（沿用 [舊版規劃](./舊版規劃_僅參考/英文配音計劃.md) 的做法）。
4. 英文版與圖文同步規劃：繁中完成後再做英文音軌或字幕，方式屆時決定。
