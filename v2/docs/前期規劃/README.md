# LoopFlow 2.0 前期規劃封存

本資料夾保存 2026-08-12～2026-08-14 的前期盤點、決策過程、雙 AI 比較與 1.x 操作證據。

## 使用界線

- 本資料夾不是實作規格，也不決定目前行為。
- 實作只依 `../實作總覽.md`、`../資料契約.md`、`../工作流程.md`、`../開發任務與路徑.md`、`../系統設定.md` 與 `../重構進度.md`。
- 封存文件可能保留當時尚未裁決、後來被否決或已被新契約取代的敘述。
- 需要追查決策理由、1.x producer／consumer 或 migration 證據時可以閱讀，但不得直接複製成 2.0 規則。
