# LoopFlow 2 圖文教學規劃

> 定位：以一個小型示範專案，帶讀者從 Rhino 3D 模型走到可更新的 Layout 圖紙。每篇是可單獨完成、存檔與回頭查找的作業階段。本文規劃教學內容，正式操作以目前版本的 [工作流程](../工作流程.md) 與公開 [指令說明](../../../docs/COMMANDS_TW.md) 核對。拍攝前再核對安裝版本與畫面文字；舊 [YT 規劃](../教學影片版/舊版規劃_僅參考/2.0教學步驟.md) 只供參考。

## 共用示範與寫法

- 使用[共用示範模型](./README.md#共用示範模型)（QTY 專用模型）的**教學副本**：3D、2D 兩份 `.3dm` 放在同一專案資料夾，另備正式 Dictionary、圖框、Tag 與最後成果圖。不要在 QTY 基準模型上操作；模型內刻意的錯誤樣本只在「常見失敗」使用。注意 LoopFlow 出圖是開 2D 檔、掛入 3D，與 QTY 的方向相反。
- 每篇固定包含：完成後會得到什麼、前置檔案與畫面、逐步操作、每步結果截圖、檢查點、常見失敗與回到哪一步、下一篇連結。指令名稱可複製；不要只靠圈選截圖表示操作。
- 截圖同時顯示 Rhino 所在檔案、操作區與結果；長對話框拆成「選項」和「確認後結果」兩張。以圖說解釋箭頭或框線。每篇首圖放成果，過程圖只留會影響判斷的畫面。
- 標題採使用者會搜尋的問題與成果，例如「Rhino 字典如何建立 Type Layers」；圖說、替代文字、檔名描述該步驟。版本與更新日期放篇首。不要把內部 schema 或測試紀錄當入門正文。

## 建議篇章

| 篇 | 讀者完成什麼 | 必拍／必截畫面 | 要講透的判斷與檢查點 |
|---|---|---|---|
| 01 開始一個專案 | 安裝後存 `.3dm`，把 Dictionary 與 Tag 來源放到正確位置 | Package Manager、`文件\LoopFlow` 來源、專案資料夾前後對照、語言選擇 | `.3dm` 所在層才是工作資料夾；1.x 與 2 不混用；Document 左鍵／右鍵用途不同。此篇結束能說出應整包搬哪個資料夾。 |
| 02 字典到模型 | Nexus 開案檢查、同步 Type Layers，模型物件換到對應圖層 | 字典少量代表欄、Nexus 1／2、同步後圖層樹、物件所屬圖層 | Dictionary 是 Type 目錄，模型 instance 資料尚未寫入；第一次選字典要與 `.3dm` 同層。不要逐欄複製字典指南。 |
| 03 模型資料與發布 | 登記高程框／空間框，寫入並檢核 Metadata，發布 Registry | 框的平面與高度、Nexus 3～6、Data Viewer、檢核成功與發布版次 | 框重疊或跨空間怎麼處理；寫入、只讀檢核、發布是三件事；資料未發布不代表 2D 已更新。完成後存檔。 |
| 04 字典差異回圈 | 改一個 Type layer，匯出差異、人工合併正式字典，再同步與發布 | Rhino 改層、Export 檔的狀態色、正式字典、再次檢核與 Registry 版次 | 匯出檔不能當正式字典；新 Type ID 需人工給新號；先判斷差異，再決定採納，不示範覆蓋正式檔。 |
| 05 3D 交給 2D | 同資料夾分開 3D／2D 檔、Worksession Attach，建立 Rhino Section 與 View | 兩檔與 `_LoopFlow_Config`、`.rws`、Section 圖 A、Text Dot 與 Anchor Frame | Nexus／Publish 在 3D；圖面工作在 2D。錨定框在 2D 模型空間；一張 Section 對一個可辨識的名稱。Sync Worksession 只 Refresh，不代 Attach。 |
| 06 可編輯線稿與圖紙 | 視需要 Extract 成圖 B，建立 Layout／Detail／圖框，編圖號並產圖目錄 | 圖 A／B 對照、`**` 起點頁與 `//` 手動頁、Layout ID 核對清單、Catalog 結果 | 圖 B 可以人工修改，更新圖 A 不會自動覆蓋圖 B；Sheet metadata 是圖號來源。複製頁最好在綁 Tag 前；插頁後要重跑 Layout ID。 |
| 07 Tag 到可檢查圖紙 | 選對 Tag、以 Laser／Grab／Index 綁定、Infuser 注入、TAG-O 檢查 | 三種綁定各一例、Part／All 結果、正常／過期／斷連並排 | 三種綁定依來源擇用，不必每顆都跑三支。`-` 未綁、`!` 過期、`?` 斷連；TAG-O 只檢查與上色。`TAG_DW` 人工填，鎖定 Tag 不自動改。 |
| 08 改版後怎麼回來 | 分別演示改圖名／頁序、改模型資料、改幾何三種情況 | 變更前後圖紙、Registry 版次、更新 Section、重新綁定前後的 TAG-O | 圖紙變更：Layout ID → Infuser → Catalog → TAG-O；資料變更：寫入／檢核／發布 → Infuser；幾何或來源變更需檢查 Section、Laser／Grab 綁定。斷連先重綁，不能只按 Infuser。 |

## 發布順序

先完成 01～03，讓新使用者能做出第一份可檢核的模型資料；再做 05～07，完成一張圖；04 與 08 作為改版與故障回查。首頁另放一張篇章地圖，標明「3D 檔」「2D 檔」「存檔停點」。

## 邊界與錄製前核對

本系列只講 LoopFlow 2 出圖主鏈；`qty/` 數量計算與 `toolkit/` 是其他產品。示範 `TAG_ITEM` 時，Tag 與家具 Block 要在同一 `.3dm`；圖 B 的人工修改需明示更新選擇。截圖和文案以正式安裝版重新操作核對，不沿用 1.x 顏色、指令或舊規劃中的版本號。
