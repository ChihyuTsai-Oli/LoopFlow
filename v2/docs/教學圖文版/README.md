## 整體作業順序

```text
1  QTY 專用模型完成
2  四個產品的教學製作   ／   QTY repo 開發（數量計算程式）
3  QTY 教學製作
```

模型是所有教學的起點。第 2 步的兩條線可以並行：QTY repo 開發仍須先過 [`測試模型.md`](../../../qty/docs/前期評估/測試模型.md) §0.4 的三道開工關卡（三家 AI 驗收模型、重評決策、多數決），教學製作則不必等這些關卡。QTY 教學要等 QTY 產品本身做出來才開始。

## 共用示範模型

所有教學（含日後的 QTY）都從**同一個 QTY 專用模型原型**出發，讓讀者在不同產品間看到同一個案子：

- 規格：[`qty/docs/前期評估/測試模型.md`](../../../qty/docs/前期評估/測試模型.md)
- 原型工作檔：`<LOOPFLOW_QTY_WORKFILES_ROOT>`（雙機路徑見工作區根目錄 `工作檔路徑.md`），目前為 `loopflow_qty_3D.3dm`、`loopflow_qty_2D.3dm`、`loopflow_qty.rws` 與測試 Dictionary
- **現況：模型尚未完成。** 正式截圖與錄影須等模型完成；在那之前只做篇章規劃與文字草稿。

做法：**原型相同，各自調整。** 模型完成後，分別複製到各產品的教學作業資料夾，再依該產品的展示需要加工（例如 R2B／R2O 補相機與燈點、R2M 補樓層框、LoopFlow 補 Layout 與 Tag）。各資料夾的副本互不共用，也各自帶自己的 `_LoopFlow_Config`、輸出資料夾與 `.rws`。各作業資料夾的位置在建立時登記到 `工作檔路徑.md`，不寫死任何一台電腦的絕對路徑。

使用時的限制：

1. **原型不直接拿來做教學操作。** 它是 QTY 正確性測試的共同基準，附 manifest、雜湊與期望答案；所有加工只在各產品的副本上做。
2. **原型刻意含有錯誤樣本**（例如 `EXT` 物件、參照失效、未命名群組、開錯檔配置）。各副本可視需要移除；保留的錯誤樣本只在「常見失敗」段落刻意使用，且要在圖說標明。
3. **Worksession 方向依產品而定。** LoopFlow 出圖是開 **2D 檔**、把 3D 掛進來；QTY 是開 **3D 檔**、把 2D 掛進來（QTY QD-26：3D 被掛進 2D 時應報錯停止）。從原型複製時要依該產品重建 `.rws`，教學中明講現在是哪一個檔案作用中。
4. 示範檔公開前須去除客戶與個人資料。

## 語言

- **中英雙語。建置階段只寫繁體中文**，全部完成後再翻成英文。
- 中英文要完全分開成兩份，還是同頁並列，**翻譯時再決定**；撰寫中文版時不要預先夾英文段落。
- 指令名、按鈕原文、圖層名、檔名一律維持英文原文，翻譯時不必改截圖。

## 每篇共同格式

完成後會得到什麼（首圖放成果）→ 前置檔案與畫面 → 逐步操作（每步配結果截圖）→ 檢查點 → 常見失敗與回到哪一步 → 下一篇連結。標明現在在 Rhino 哪個檔、或在 Blender／Octane／BIM 哪一端。
