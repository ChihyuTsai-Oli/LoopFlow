## 主輔關係

- **圖文為主**：分段詳述，每篇是一個可單獨完成、存檔、回頭查找的作業階段。
- **影片為輔**：一條完整操作展示，章節對應圖文篇號。規劃見 [`../教學影片版/`](../教學影片版/README.md)。
- 舊 YouTube 10 步分鏡與英文配音計劃已移到 [`../教學影片版/舊版規劃_僅參考/`](../教學影片版/舊版規劃_僅參考/README.md)，只供參考。

## 共用示範模型

所有教學（含日後的 QTY）使用**同一組 QTY 專用模型**，讓讀者在不同產品間看到同一個案子：

- 規格：[`qty/docs/前期評估/測試模型.md`](../../../qty/docs/前期評估/測試模型.md)
- 工作檔：`<LOOPFLOW_QTY_WORKFILES_ROOT>`（雙機路徑見工作區根目錄 `工作檔路徑.md`），目前為 `loopflow_qty_3D.3dm`、`loopflow_qty_2D.3dm`、`loopflow_qty.rws` 與測試 Dictionary
- **現況：模型尚未完成。** 正式截圖與錄影須等模型完成；在那之前只做篇章規劃與文字草稿。

使用時的限制：

1. **不要直接在 QTY 基準模型上做教學操作。** 那份是 QTY 正確性測試的共同基準，附 manifest、雜湊與期望答案；教學另存一份**教學副本**，相機、燈點、樓層框、Layout、Tag 與各產品輸出資料夾（`_LoopFlow_Config`、R2B／R2O／R2M 輸出）都只放在副本裡。副本的位置與檔名在模型完成時決定，並登記到 `工作檔路徑.md`，不寫死任何一台電腦的絕對路徑。
2. **QTY 模型刻意含有錯誤樣本**（例如 `EXT` 物件、參照失效、未命名群組、開錯檔配置）。一般教學只用正常部分；錯誤樣本只在「常見失敗」段落刻意使用，且要在圖說標明。
3. **Worksession 方向兩個產品相反。** LoopFlow 出圖是開 **2D 檔**、把 3D 掛進來；QTY 是開 **3D 檔**、把 2D 掛進來（QTY QD-26：3D 被掛進 2D 時應報錯停止）。教學副本的 `.rws` 要分開準備，教學中要明講現在是哪一個檔案作用中。
4. 示範檔公開前須去除客戶與個人資料。

## 語言

- **中英雙語。建置階段只寫繁體中文**，全部完成後再翻成英文。
- 中英文要完全分開成兩份，還是同頁並列，**翻譯時再決定**；撰寫中文版時不要預先夾英文段落。
- 指令名、按鈕原文、圖層名、檔名一律維持英文原文，翻譯時不必改截圖。

## 每篇共同格式

完成後會得到什麼（首圖放成果）→ 前置檔案與畫面 → 逐步操作（每步配結果截圖）→ 檢查點 → 常見失敗與回到哪一步 → 下一篇連結。標明現在在 Rhino 哪個檔、或在 Blender／Octane／BIM 哪一端。
